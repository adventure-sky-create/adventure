# 星际坦克战线 (Stellar Tank Frontline) — 技术设计文档

> 面向 solo builder（AI 代码生成）的可执行规格说明。文档目标：让 builder 读完即可直接产出可运行的网页游戏代码，无需二次猜测设计意图。

---

## 1. 项目概述

### 1.1 一句话定位
一款**科技风网页坦克大战游戏**，融合经典 Battle City 基地防守、Roguelike 关卡升级、双摇杆射击、Boss 多阶段战斗等主流玩法，纯前端单文件运行，开箱即玩。

### 1.2 核心体验关键词
- **科技风视觉**：深空霓虹、网格战场、发光弹道、粒子特效
- **玩法多样**：移动射击 + 基地防守 + 关卡升级 + Boss 战 + 多武器切换
- **爽快反馈**：屏幕震动、击中粒子、击杀连击、伤害数字飘字
- **成长感**：Roguelike 三选一升级，局内变强

### 1.3 约束与非目标
- **约束**：纯前端，单 HTML 文件（内嵌 CSS/JS）或最多拆为 `index.html` + `game.js` + `style.css` 三个文件；无后端、无外部资源依赖（字体可用系统字体或 Google Fonts CDN）。
- **非目标**：不做多人联机、不做账号存档云同步、不做付费内购、不做移动端原生 App。

## 3. 游戏设计

### 3.1 核心玩法循环

#### 剧情模式（20 关通关）

```
进入关卡 (Level N)
   │  ├─ 目标 A: 消灭所有敌人  (普通关)

   │  └─ 目标 C: 击败 Boss      (Boss关, 每5层1次)
   │
   ▼
关卡结算 (击杀数/连击/剩余血量 → 得分)
   │
   ▼

   │
   ▼
界面 2: 强化 3 选 1 (额外第 2 次强化)
   │  ★ 从同一卡池再抽 3 张, 可与界面1不同
   │
   ▼
界面 3: 武器解锁 3 选 1 ◄── 每 2 关 + 未满上限时显示

   │  ├─ 选择装备为【副武器】(自动开火)
   │  ├─ 剧情模式：装备达 3 把上限后不再出现此界面
   │  └─ 无尽/创造模式：无上限，每 2 关正常显示

   │  ★ 敌人血量/伤害随玩家装备武器数增加  │ 动态平衡
   │  ★ 玩家获得强化后, 下关敌人按公式缩放 │
   │                                    │
   ▼                                    │

                        │
   每 5 关 → Boss 战 ◄──┘
                        │
   第 5/10/15... 关 Boss 击败 → 继续 / 第 20 关最终 Boss → 通关
```

```
   │

敌人同步增强 (玩家越强化, 敌人越强)
```

#### 创造模式（Creative）—— 自由搭配，无限制战斗

```
选择创造模式
   │
   ▼
开局配置界面
   ├─ Step 1: 选择 2 把初始武器（从 10 种武器池中自由选择）
   │    ★ 可选主炮(CANNON)也可不选
   │    ★ 可选 2 把副武器 / 1 主炮+1 副武器 / 2 独立武器 等任意组合
   │
   ├─ Step 2: 一次性选择 20 张强化卡
   │    ★ 从完整强化卡池抽 20 张，每张三选一，共 20 轮
   │    ★ 可全部堆同一方向（极端构建）或分散多种强化
   │    ★ 选择完成后所有强化立即生效
   │
   ▼
进入战斗（无关卡停顿）
   │  ├─ 怪物同普通关属性
   │  ├─ 无关卡结算界面，无强化 3 选 1 中断
   │  ├─ 自动刷怪：
   │  │   ├─ 定时器：每 N 秒自动刷一批怪
   │  │   └─ 数量触发：场上怪数量 < 阈值时立即刷下一批
   │  └─ 难度持续缓慢递增（血量×1.02/波）
   │
   ▼
持续战斗（无尽波次）
   │  ★ 无胜负目标，纯粹测试构建强度
   │  ★ 统计波数、击杀数、生存时间
   │  ★ 死亡后显示完整构建统计
```

**创造模式设计要点**：
- **自由度最高**：开局任意 2 把武器 + 20 次强化自由搭配，测试极端 build
- **无打断**：全程无关卡结算界面，战斗无缝衔接
- **自动刷怪逻辑**：
  ```
  spawnTimer = 3s                    // 每 3 秒检查一次
  minOnField = 5                     // 场上少于 5 只立即刷
  baseSpawnCount = 3 + waveIndex*0.3 // 每波数量递增
  enemyTypeMix = randNormalEnemy()   // 随机普通敌人
  eliteChance = 0.05 + waveIndex*0.002 // 精英概率随波次缓慢上升
  ```
- **波次标记**：屏幕左上显示「第 N 波」，死亡结算统计总波数
- **适合场景**：快速测试武器组合、验证 build 强度、开发调试

#### 武器系统核心规则
- **主炮 (CANNON)**：每局固定携带，玩家手动操控瞄准/射击（创造模式可选）
- **副武器**：每 2 关解锁 1 把，**自动开火**（无需玩家操作），独立瞄准最近敌人
- **独立武器**：无人机 (DRONE)、地雷 (MINE) 不占副武器槽，通过强化卡获得
- **特殊武器**：核弹 (NUKE) 从精英/Boss 掉落，Q 键释放
- **武器联动**：副武器之间可触发联动效果（如激光+无人机=激光蜂群）
- **动态平衡**：敌人强度根据玩家武器数量/等级实时缩放，防止数值膨胀

## 4. 玩法系统详细设计

### 4.1 关卡系统

#### 剧情模式（20 关）
- **关卡总数**：固定 20 关，第 20 关为最终 Boss 战，击败即通关。
- **关卡类型**（按 `level % 5` 决定）：
  - 第 1~4 关槽位：普通战（消灭 N 个敌人）
  - 第 5/10/15/20 关：Boss 战
  - 每 3 关插入一关"防守战"（守护基地 60 秒）
- **难度曲线**：每关敌人血量 ×1.08、数量 +1、刷新间隔 ×0.95。

#### 敌人动态缩放公式（双模式通用）

每关结束后，根据玩家当前武器配置动态调整下一关敌人属性：

```
// 玩家强度评分
playerPower = (1 + 副武器数量 × 0.25)          // 每把副武器 +25%
             × (1 + 独立武器数量 × 0.3)       // 每把独立武器 +30%
             × (1 + Σ武器升级等级 × 0.05)     // 每级强化 +5%

// 敌人缩放
enemyHP  = baseHP  × (1 + (level-1) × 0.08) × playerPower
enemyDMG = baseDMG × (1 + (level-1) × 0.06) × sqrt(playerPower)
enemySPD = baseSPD × (1 + (level-1) × 0.01)  // 速度微增不缩放
enemyCount = baseCount + floor((level-1) × 0.3) + floor(副武器数量 × 0.5)

// Boss 缩放
bossHP  = baseBossHP  × (1 + (level/5-1) × 0.4) × playerPower
bossDMG = baseBossDMG × (1 + (level/5-1) × 0.3) × playerPower
```

**设计意图**：玩家武器越多/强化越高，下一关敌人越强，保证每关挑战感不崩。强化越高 → 敌人越多越强 → 逼着玩家选择新的强化路线，而不是堆同一类强化。

#### 无尽模式（无限关卡）
- **关卡总数**：无上限，玩家死亡时记录最高关卡数。
- **关卡类型**：同剧情模式（普通战/防守战/Boss 战循环），但 Boss 随关卡持续强化。
- **难度曲线**（比剧情模式更陡峭）：
  - 每关敌人血量 ×1.12、数量 +2、刷新间隔 ×0.93
  - 精英怪刷新率：第 2 关起即可出现，概率 = `min(level/15, 0.5)`
  - Boss 血量公式：`baseHp × (1 + level/20)`，每 10 关出现"强化 Boss"（血量 ×2 + 多 1 个狂暴阶段）
  - 第 50 关起，普通敌人开始出现精英变种
  - 第 100 关起，场上敌人上限翻倍
- **升级卡池增强**：无尽模式下，每 5 关（非 Boss 关）的升级卡池额外包含 1 张"稀有强化"卡（属性加成翻倍）。

#### 两种模式通用
- **地图生成**：程序化生成障碍物（钢铁墙不可破坏、砖墙可破坏、水域不可通行但可射击越过）。地图分 3 种布局模板随机选取。

### 4.2 敌人系统

#### 普通敌人

| 敌人类型 | 代号 | 血量 | 速度 | 特点 | AI 行为 |
|---|---|---|---|---|---|
| 侦察兵 | SCOUT | 2 | 快 | 脆弱、成群 | 直线冲向玩家，接触伤害 |
| 重装兵 | HEAVY | 8 | 慢 | 高血厚甲、伤害高 | 慢速逼近，远程炮击 |
| 狙击手 | SNIPER | 3 | 中 | 超远射程、高单体伤害 | 保持距离，瞄准玩家预判射击 |
| 自爆兵 | BOMBER | 4 | 极快 | 死亡爆炸范围伤害 | 直冲玩家，靠近自爆 |
| 散弹兵 | SPREAD | 4 | 中 | 三连发散射 | 中距离游走散射 |

#### 精英敌人（ELITE）——仅在关卡难度≥3时随机出现，击杀必掉落核弹

| 精英类型 | 代号 | 血量 | 速度 | 特点 | AI 行为 | 掉落 |
|---|---|---|---|---|---|---|
| 精英战士 | ELITE_WARRIOR | 20 | 中 | 双持主炮，装甲厚实 | 保持中距离，高射速双炮齐射，偶尔冲锋 | 核弹(5%) + 血包(100%) |
| 精英术士 | ELITE_SORCERER | 15 | 慢 | 召唤+远程，瞬移逃脱 | 远距离蓄力大弹攻击，血量<50%时瞬移，召唤2个SCOUT | 核弹(5%) + 大招充能(100%) |
| 精英猎手 | ELITE_HUNTER | 18 | 极快 | 追踪+高速冲撞，预判射击 | 高速游走，预判玩家位置射击，周期性发射追踪导弹 | 核弹(7%) + 弹药补给(100%) |
| 精英守卫 | ELITE_GUARDIAN | 30 | 极慢 | 超高血量，护盾再生 | 慢速移动，持续生成护盾(可被打破)，死亡时爆炸范围伤害 | 核弹(10%) + 护盾(100%) |

- **精英刷新**：第 3 关起，每关有 `level/25` 概率在普通敌人刷新时替换一个为精英。Boss 关保底刷 1 只精英。
- **AI 寻路**：简化 A* 或网格 BFS（地图按 40px 网格化）；狙击手/重装兵保持射程距离，近战类型直接寻路贴脸。
- **刷新机制**：从战场边缘 4 个出生点轮流刷新，场上同时存在上限 = `5 + level/3`。

### 4.3 Boss 设计（核心卖点）

#### Boss 1（第 5 关）——「铁壁哨兵」Iron Sentinel
- 形态：四足机甲炮台，固定中央，旋转炮塔。
- 血量：80
- 阶段：
  - 阶段1（HP 100%~60%）：**360°旋转扫射弹幕**（每 30° 一发，慢速）+ **螺旋弹幕**（每轮递增角度偏移）
  - 阶段2（HP 60%~30%）：追加**追踪导弹**（2 发/轮，可被击落）+ **十字弹幕**（横向+纵向交替）
  - 阶段3（HP 30%~0%）：狂暴，弹幕间隔减半 + 召唤 2 个 SCOUT + **散射弹幕**（12 发扇形随机偏移）

#### Boss 2（第 10 关）——「裂空巡洋」Sky裂痕
- 形态：悬浮飞行堡垒，会位移（沿椭圆轨道绕玩家飞）。
- 血量：150
- 阶段：
  - 阶段1：**激光扫射**（水平/垂直两道激光交叉扫描，有预警线）
  - 阶段2：**落雷轰炸**（地面随机 5 个预警圈，0.5秒后爆炸）+ **扇形弹幕**（18 发 120°扇形）
  - 阶段3：召唤小怪群（4 SCOUT + 1 SPREAD）+ **环形弹幕**（3 圈同时发射，内外交叉）
  - 阶段4（狂暴）：激光 + 落雷 + 弹幕**三合一**同时释放

#### Boss 3（第 15 关）——「量子双子」Quantum Twins
- 形态：两只共生 Boss（紫/青配色），需同时击杀（10 秒内不死则复活另一只）。
- 血量：每只 60
- 阶段：
  - 阶段1：**镜像弹幕**（两只 Boss 对称方向射击，轨迹交错）
  - 阶段2：**量子纠缠**（一只 Boss 发射时另一只同步发射，弹幕交叉形成网格）
  - 阶段3：**瞬移散射**（两只 Boss 周期性瞬移 + 瞬移后立即扇形弹幕）
  - 特殊机制：两只 Boss 距离过近时产生**能量护盾**，需将其分开

#### 最终 Boss（第 20 关）——「终焉引擎」Doom Engine
- 血量：400，三阶段大形态变换，融合前述所有机制 + 全屏弹幕 + 弱点核心暴露机制。
- 形态变换：

> - 独立武器（无人机/地雷）的解锁卡 + 强化卡可在任意关卡抽取

#### 武器解锁流程

```
每关通关后 →
  ┌─────────────────────────────────────────────┐
  │ 界面 1：三选一升级卡（强化/属性/被动）         │
  │ 武器强化仅包含: 现有武器伤害/射速/特殊强化       │
  │ (不包含解锁新武器)                             │
  └─────────────────────────────────────────────┘
                        │
                        ▼ (每 2 关触发 + 未满上限时)
  ┌─────────────────────────────────────────────┐
  │ 界面 2：三选一武器解锁 (仅在第2/4/6/8...关)   │
  │ 剧情模式：已达 3 把上限时跳过此界面            │
  │ 从 7 种副武器池中随机抽 3 把未解锁武器          │
  │ 玩家选 1 把 → 立即装备为副武器（自动开火）      │
  │ ★ 独立武器（无人机/地雷）不在此池，通过升级卡获得 │
  └─────────────────────────────────────────────┘
```

#### 副武器数量上限
- **剧情模式**：最多同时装备 **3 把**副武器。超过时替换选择（放弃旧的解锁新的）。
- **无尽模式**：副武器数量**无上限**，可装备全部 7 种副武器同时开火。
- **创造模式**：开局选择 2 把武器（含主炮可选），副武器槽无上限。

同时装备特定武器组合时，触发额外协同效果：

### 4.5 升级 / 技能系统（Roguelike）

**关卡结算**：双强化 + 武器解锁流程
1. **强化界面 1**（每关必触发）：从强化卡池随机抽 3 张，玩家选 1
2. **强化界面 2**（每关必触发，额外第 2 次）：从同一卡池再抽 3 张，玩家选 1（可与界面 1 选择相同方向叠加升级）
3. **武器解锁界面**（每 2 关触发，第 2/4/6/8...关）：从副武器池随机抽 3 把未解锁武器，选 1 装备
4. 所有界面完成后，敌人属性已根据本次全部升级动态缩放

#### 主升级卡池分类

- **武器强化类**：43 张武器专属强化卡（详见 §4.4 武器升级卡池）
- **独立武器解锁**：无人机系统解锁、地雷系统解锁（仅此两种在此）
- **属性类**：最大血量、移动速度、护盾上限等全局属性
- **被动类**：吸血/弹射/暴击/穿透/磁吸/护盾
- **联动强化类**：强化已有武器组合的联动效果
- **大招充能加速类**：大招所需击杀数减少

> **核心规则**：强化卡池**不包含**任何副武器解锁。副武器（激光/散弹/导弹等）只通过每 2 关的武器解锁界面获得。独立武器（无人机/地雷）的解锁和强化在强化卡池中。武器强化卡共 43 张（3 武器 × 5 方向 + 7 武器 × 4 方向），具体效果见 §4.4 末尾的武器升级卡池表。玩家每关可获得 2 次强化机会，越强化敌人下一关越强（详见 §4.1 动态缩放公式）。

### 5.3 游戏循环与时序

固定时间步长（Fixed Timestep），保证物理稳定：

```javascript
// 伪代码
const FIXED_DT = 1000 / 60;   // 60 FPS 逻辑步长
let accumulator = 0;
let lastTime = performance.now();

function frame(now) {
  let delta = now - lastTime;
  lastTime = now;
  accumulator += delta;
  // 防止切后台后累积爆炸
  if (accumulator > 250) accumulator = 250;
  while (accumulator >= FIXED_DT) {
    update(FIXED_DT / 1000);   // 秒为单位
    accumulator -= FIXED_DT;
  }
  render(interpolation = accumulator / FIXED_DT);
  requestAnimationFrame(frame);
}
```

- `update(dt)`：依次更新 输入 → 玩家 → 敌人AI → 子弹 → 碰撞 → 粒子 → 关卡状态 → HUD。
- `render(alpha)`：清屏 → 绘制地图 → 实体 → 粒子 → HUD（HUD 用 DOM 或 Canvas 均可，推荐关键 HUD 用 DOM + CSS 易实现科技面板，血条/弹道用 Canvas）。

      this.blockCd = CONFIG.WEAPONS.DRONE.blockInterval;
    }
  }

## 7. 关键算法

### 7.1 碰撞检测

- **实体间**：圆形碰撞 `dist2 = (dx*dx+dy*dy); hit = dist2 < (r1+r2)^2`（避免开方）。
- **子弹 vs 墙体**：AABB（墙体为矩形）。子弹碰可破坏砖墙 → 砖墙血量-1，砖墙血量 0 时移除。
- **子弹 vs 实体**：圆形碰撞。
- **空间优化**：敌人和子弹数量 < 200，直接 O(n²) 即可，无需四叉树。

### 7.2 敌人 AI（简化状态机）

```javascript
aiUpdate(dt, player, map) {
  const dist = Math.hypot(player.x-this.x, player.y-this.y);
  switch (this.type) {
    case 'SCOUT': case 'BOMBER':
      // 直冲玩家
      this.angle = Math.atan2(player.y-this.y, player.x-this.x);
      this.vx = Math.cos(this.angle)*this.speed;
      this.vy = Math.sin(this.angle)*this.speed;
      break;
    case 'SNIPER':
      // 保持 350~450 距离, 定时射击
      if (dist < 350) { /* 后退 */ }
      else if (dist > 450) { /* 前进 */ }
      else { this.vx=0; this.vy=0; this.tryShoot(player); }
      break;
    case 'HEAVY':
      // 慢速逼近, 远距离炮击
      this.angle = Math.atan2(player.y-this.y, player.x-this.x);
      this.vx = Math.cos(this.angle)*this.speed;
      this.vy = Math.sin(this.angle)*this.speed;
      if (dist < 400) this.tryShoot(player);
      break;
    case 'SPREAD':
      // 中距离游走 + 散射
      break;
  }
  // 障碍物避让: 若下一步撞墙则尝试绕行(简化: 旋转90°试一次)
}
```

### 7.6 无尽模式难度缩放算法

```javascript
// LevelManager 中无尽模式难度计算
class LevelManager {
  constructor() {
    this.level = 0;
    this.isEndless = CONFIG.MODE === 'endless';
    this.maxLevelReached = parseInt(localStorage.getItem('tankMaxLevel') || '0');
  }

  // 每关开始前调用，计算本关参数
  calcLevelParams(level) {
    if (!this.isEndless) {
      // 剧情模式：20关封顶
      return this.calcStoryParams(level);
    }
    // 无尽模式
    const cfg = CONFIG.ENDLESS;
    const hpMul = Math.pow(cfg.difficulty.hpMul, level - 1);
    const spawnCount = cfg.difficulty.countAdd * level;
    const spawnInterval = Math.pow(cfg.difficulty.intervalMul, level - 1);
    const enemyCap = level >= cfg.enemyCapDoubleStart
      ? CONFIG.ENEMY_SPAWN_MAX_ENDLESS * 2
      : CONFIG.ENEMY_SPAWN_MAX_ENDLESS;

    // 精英怪概率
    const eliteProb = level >= cfg.eliteStartLevel
      ? cfg.eliteProbFormula(level)
      : 0;

    // Boss 血量缩放
    const bossHpScale = cfg.bossHpScale(level);

    // 强化 Boss 判断
    const isEnhancedBoss = level % cfg.enhancedBossEvery === 0 && level % 5 === 0;

    // 精英变种出现
    const allowEliteVariant = level >= cfg.eliteVariantStart;

    return {
      hpMul, spawnCount, spawnInterval, enemyCap,
      eliteProb, bossHpScale, isEnhancedBoss, allowEliteVariant,
      isBossLevel: level % 5 === 0,
      isDefenseLevel: level % 3 === 0 && level % 5 !== 0,
    };
  }

  // 无尽模式：关卡结算时保存最高记录
  onLevelComplete(level) {
    if (this.isEndless && level > this.maxLevelReached) {
      this.maxLevelReached = level;
      localStorage.setItem('tankMaxLevel', String(level));
    }
  }

  // 无尽模式死亡时保存完整统计
  onPlayerDeath(stats) {
    if (!this.isEndless) return;
    const record = {
      maxLevel: this.maxLevelReached,
      lastLevel: stats.level,
      lastScore: stats.score,
      lastKills: stats.kills,
      timeSurvived: stats.time,
      weaponsUnlocked: stats.weapons,
      date: new Date().toISOString(),
    };
    const history = JSON.parse(localStorage.getItem('tankEndlessHistory') || '[]');
    history.push(record);
    // 只保留最近 10 条
    if (history.length > 10) history.shift();
    localStorage.setItem('tankEndlessHistory', JSON.stringify(history));
  }

  // 无尽模式升级卡池：每 5 关(非Boss)添加稀有卡
  getUpgradePool(level) {
    const pool = this.baseUpgradePool.slice();
    if (this.isEndless && level > 0 && level % 5 === 0 && level % 25 !== 0) {
      // 25 = 5 和 10 的最小公倍数，即每25关Boss关不重复加
      pool.push(...this.rareUpgradePool);
    }
    return pool;
  }
}
```

## 10. 性能要求

- 目标 60 FPS（Canvas 渲染）
- **剧情模式实体预估**：玩家1 + 无人机≤4 + 地雷≤5 + 敌人≤12 + 精英≤2 + Boss1 + 子弹≤100 + 粒子≤400
- **无尽模式实体预估**（高关卡）：玩家1 + 无人机≤6 + 地雷≤8 + 敌人≤20 + 精英≤4 + Boss1 + 子弹≤150 + 粒子≤600
- **创造模式实体预估**（持续高波次）：玩家1 + 无人机≤5 + 地雷≤6 + 敌人≤25 + 精英≤3 + 子弹≤120 + 粒子≤500
- 优化手段：
  - 粒子用对象池复用
  - `shadowBlur` 慎用（只对少量关键发光元素用，或预渲染到离屏 Canvas）
  - 屏幕外的实体不渲染（视口裁剪）
  - 无人机用简单位置计算（轨道角度递增），无需复杂物理
  - 毒气云/火焰用区域效果（AOE）而非逐帧实体检测
- 兼容：最低支持 1280×720，窗口小于此尺寸时等比缩放 Canvas（CSS `transform: scale`）。
